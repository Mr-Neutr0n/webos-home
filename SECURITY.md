# Reporting a vulnerability

Use the repository's GitHub security advisory page to report a vulnerability
privately. Include the affected version, a small reproduction, and the scope
of the resulting access. Do not include client keys, node state, private keys,
or the address of a device you do not own.

Only the current source tree is maintained. This project does not maintain
webOS firmware, Homebrew Channel, Tailscale, or third-party rooting tools.
Report flaws in those components to their maintainers.
